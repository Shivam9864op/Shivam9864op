# Shivam Sharma

API and webhook reliability QA builder from India.

I help teams test and harden workflow integrations: reproduce failures, check validation and duplicate handling, verify retries and logs, and document expected versus actual behaviour. My work is built with JavaScript/Node.js, REST APIs, webhooks, and safe synthetic data.
